# ♜ Последний Бастион

Одиночная 2.5D-игра в жанре «защита замка». Отстройте поселение, укрепите стены и переживите **25 волн** мертвецов и пятерых боссов.

Бой полностью автоматический — игрок только улучшает здания и оборону и наблюдает, как защитники держат стену.

## Запуск

Сборка не нужна — чистый HTML5 Canvas + JavaScript.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

(Можно открыть и `index.html` напрямую.)

## Как играть

- Между волнами идёт фаза подготовки (автостарт через 12 с, или кнопка «В бой!» / пробел).
- Кликайте по зданиям на карте или по карточкам в панели справа, чтобы улучшать их.
- Золото дают за каждого убитого зомби и за каждую отбитую волну.
- Если стена падёт — волну можно переиграть, золото, добытое в бою, сохраняется.
- Прогресс сохраняется в браузере автоматически. Скорость x1/x2/x3, пауза — `P`.

### Поселение (6 зданий)

| Здание | Бонус |
|---|---|
| 🏛️ Ратуша | +12% золота за уровень |
| ⚒️ Кузница | +10% урона всей обороны |
| 🎯 Стрельбище | скорострельность лучников и шанс крита |
| 🛠️ Мастерская | перезарядка осадных орудий и радиус взрыва |
| ⛏️ Каменотёсы | прочность стены и её ремонт в бою |
| ⚗️ Алхимик | урон горящего воска, огненные стрелы, пылающие снаряды |

### Оборона

🧱 Стены (частокол → камень → крепость) · 🏹 Лучники · 🔥 Горящий воск (котлы опрокидывают воск со стены) · 🔱 Баллисты (пробивают насквозь) · ☄️ Катапульты · ⚖️ Требушеты

### Враги

Зомби, бегуны, громилы, раздутые (взрываются у стены), плевуны (кислота издалека), вожаки стаи и боссы: **Мясник** (5), **Некромант** (10), **Каменный Колосс** (15), **Чумной Титан** (20), **Король Мёртвых** (25).

## Структура

```
index.html
css/style.css
js/config.js   — данные, формулы баланса, состав волн
js/engine.js   — игровая логика (без DOM)
js/render.js   — 2.5D-отрисовка и анимации
js/audio.js    — синтезированные звуки (WebAudio)
js/ui.js       — HUD, панель улучшений, окна
js/main.js     — запуск, игровой цикл, сохранения
tools/sim.js   — headless-прогон всех 25 волн для проверки баланса
```

Проверка баланса: `node tools/sim.js 10 balanced` (или `lazy`).
